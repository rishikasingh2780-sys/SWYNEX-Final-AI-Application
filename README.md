SWYNEX Final AI Application

Project Name

AI Text Analyzer

1. Problem Statement

Understanding the sentiment of written text can be difficult when dealing with large amounts of information. This application helps users analyze text and identify whether its sentiment is Positive, Negative, or Neutral.

2. Technologies Used

- Python
- Streamlit
- Google Gemini AI API

3. Project Method

The application accepts text from users and sends it to Google's Gemini AI model for analysis.

The AI processes the input and generates a sentiment analysis result.

Streamlit provides a simple and interactive user interface.

4. Key Features

- Text input
- AI-powered sentiment analysis
- Positive sentiment detection
- Negative sentiment detection
- Neutral sentiment detection

5. Demo and Testing

The application was tested using three different examples:

- Positive text
- Negative text
- Neutral text

The application generated sentiment results for the different inputs.

6. Limitations

- AI predictions may not always be accurate.
- Sarcasm and complex language can affect results.
- Internet connectivity is required.
- Results depend on the AI model and input quality.

7. Ethical Considerations

- Avoid entering sensitive personal information.
- AI-generated results should be checked by humans.
- User information should be handled responsibly.
- AI predictions should not be considered absolute facts.

8. Conclusion

This project helped me gain practical experience in Python programming, AI integration, API connectivity, and application development using Streamlit.
